# BioFAIRnCARE

An electronic laboratory notebook (ELN) following FAIR and CARE principles and OKF format

*Formerly Lab Vault (MyName_notes).*

BioFAIRnCARE is the PC lab's note-taking template for biological research students: daily logs,
experiment records, samples, protocols, data references, literature notes and ideas, all as plain
Markdown files connected by links, tags and properties. It follows the FAIR and CARE principles
(#BeFAIRandCARE) and the Open Knowledge Format (OKF), so its knowledge can also be read by other
tools.

- **Start here:** open the folder as a vault in [Obsidian](https://obsidian.md), then read
  `Resources/lab_resources/NoteTaking/New Student Note-Taking Guide.md`.
- **Keep your copy private:** create your own private repository from this template (do not use
  *Fork*); see `Resources/lab_resources/NoteTaking/Obsidian guide.md`.
- **What's inside:** daily notes that spawn FAIR experiment records from 32 versioned templates
  (biospecimens, nucleic acids, proteins, cell assays, xenografts, omics, modelling, ML, data
  analysis), registers for samples, materials, protocols and data, FAIR/CARE guides, worked
  examples in `_Examples/`, and a validator (`Resources/tools/validate_vault.py`, Python
  standard library) plus an in-Obsidian *Vault Health* check.
- **Changes and upgrades:** `CHANGELOG.md`, `UPGRADE.md`.
