# MTT cytotoxicity v1.0.0

## Procedure
1. Seed 5 000 cells/well in 96-well plates; attach overnight.
2. Add compound in an 8-point half-log series (0–100 µM), vehicle 0.1 % DMSO; 72 h.
3. Add MTT 0.5 mg/mL for 4 h; dissolve formazan in DMSO; read 570 nm (reference 630 nm).
4. Fit a 4-parameter logistic curve; report IC50 with 95 % CI.
