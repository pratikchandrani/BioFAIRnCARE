# Examples — fictional, safe to delete

Everything in `_Examples/` is **made up** for learning: people, samples, numbers and data
locations are fictional. Start with the demo daily note [[_Examples/daily_notes/2026-01-15|2026-01-15]]
and follow its links to one worked experiment per category (A–G).

When you are comfortable, **delete the whole `_Examples/` folder**. Nothing outside it links here,
so your vault stays valid (run the validator or open *Vault Health* to confirm).
