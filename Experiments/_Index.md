# Experiments

Every experiment note (EXP- IDs), created with the *New experiment* command.

Create experiments from a daily note with **New experiment** (`Ctrl/Cmd+Alt+E`), log later work
with **Log to experiment** (`Ctrl/Cmd+Alt+L`). Browse templates in the [[Experiment catalogue]].
